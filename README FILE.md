## Projects

### 1. 📊 Mental Health & Social Media Balance Analysis
> *Statistics & Probability | Individual Project*

A data-driven statistical study investigating the relationship between
social media usage patterns and mental health indicators.

**Dataset:** 500 participants (sourced from Kaggle)
**Tools:** Python, Pandas, NumPy, Matplotlib

**Key Findings:**
- Strong negative correlation between screen time and happiness (r = −0.71)
- Each additional hour of screen time reduces happiness by 0.62 points (R² = 0.50)
- No statistically significant gender difference in happiness (p = 0.984)

**Techniques Used:**
- Descriptive Statistics
- Pearson Correlation Analysis
- Simple Linear Regression
- Permutation Hypothesis Testing

### 2. 🌿 AI-Based Potato Disease Classification System
> *Machine Learning & Deep Learning | Individual Project*

A deep learning model designed to detect potato leaf diseases —
**Early Blight** and **Late Blight** — to support agricultural
productivity and reduce global crop losses.

**Tools:** TensorFlow, Keras, FastAPI, Uvicorn, NumPy, Pandas, Matplotlib

**Key Features:**
- Convolutional Neural Network (CNN) for image classification
- Deployed as a REST API using FastAPI and Uvicorn
- Supports early detection to minimize agricultural damage
