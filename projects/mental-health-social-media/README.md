# Mental Health & Social Media Balance Analysis

## Project Overview
A data-driven statistical study investigating the relationship between
social media usage patterns and mental health indicators.

## Dataset
- Source: Kaggle (Public Dataset)
- Size: 500 participants
- Variables: Screen time, Happiness Index, Stress Level, Sleep Quality, Exercise Frequency

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Key Findings
- Strong negative correlation between screen time and happiness (r = −0.71)
- Each additional hour of screen time reduces happiness by 0.62 points
- R² = 0.50 (screen time explains 50% of happiness variance)
- No significant gender difference in happiness (p = 0.984)
